# LACTF2025 Writeups  
[LACTF Website](https://lac.tf/)  

This repository contains detailed writeups for the challenges from LACTF 2025. Each challenge is organized into its own directory, named after the respective problem.  

We ended up in the **Top 20%** of the competition! 🎉

## Structure  

Each challenge directory includes:  
- **`solution.md`** – A comprehensive explanation of the challenge and its solution.  
- **`solution.??`** – If applicable, a script or exploit used to solve the challenge.
- **Original Challenge Files** – Any provided files (binaries, source code, data, etc.).
